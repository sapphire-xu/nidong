# 泥洞 · 视觉设计说明

给视觉实现 / 原型用。这不是营销海报，是一块长期停在桌面顶上的系统级小物件。请按「菜单栏 / 灵动岛」的密度来设计，不要做成手机 App 首页或数据大屏。

可交互原型：[`prototype/index.html`](prototype/index.html)（浏览器直接打开）。

产品：东北大学桌面小看板  
平台：Windows 11、macOS 14+  
形态：始终置顶、贴屏幕上沿、悬停展开  
日期：2026-09-07

---

## 1. 一句话

泥洞是贴在屏幕上方的一条窄岛。平时几乎不占地方；鼠标悬停后向下展开，一眼看到卡里还有多少钱、网费还够不够、电会不会停、今天下一节课在哪。

## 2. 设计原则

1. **先是桌面公民，再是校园产品。** 收起态必须能和壁纸、刘海、摄像头、Windows 小组件和平共处。不要厚重描边、不要大 Logo。
2. **三秒读完。** 展开后，余额用大数字，课表用时间轴，不要表格。
3. **东大蓝压住「泥洞」的土味。** 名字可以痞，界面必须干净。幽默只出现在空状态文案和关于页，不出现在余额数字旁边。
4. **状态比装饰重要。** 低余额、即将上课、登录失效、校外课表拉不到，都要有独立视觉，不能只靠 toast。
5. **深浅两套，跟系统。** 默认跟随 OS。宿舍关灯用深色；教室投影用浅色。
6. **不要拟物食堂、不要校徽当背景平铺、不要渐变彩虹卡片。**

## 3. 用户与场景

| 人 | 场景 | 界面要做什么 |
|---|---|---|
| 大一，宿舍电脑常开 | 打游戏/写作业时余光看一眼 | 收起态就能看到「下一节还有多久」 |
| 上课前 10 分钟 | 抓起鼠标确认教室 | 展开后今日课表第一条高亮 |
| 食堂排队 | 偶尔看卡余额 | 大数字，单位「元」 |
| 网费/电费见底 | 不想突然断 | 余额卡片变警告色，不要惊吓红满屏 |
| 第一次使用 | 学号密码 + 可能短信 | 登录叠在岛下方，短，不要独立浏览器风窗口 |

## 4. 气质与品牌

**关键词：** 克制、贴边、夜色、东大蓝、洞口一盏灯。

「泥洞」不是泥巴 UI。把它理解成：校园生活的一条窄缝，缝里透出一点校蓝。

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg-island` | `#F4F7FB` 88% 毛玻璃 | `#12161C` 78% 毛玻璃 | 岛的底板 |
| `--bg-raised` | `#FFFFFF` | `#1C222C` | 余额卡片 |
| `--ink` | `#1A2433` | `#E8EEF6` | 主文字 |
| `--ink-dim` | `#5C6B80` | `#93A1B5` | 次要文字、单位 |
| `--neu-blue` | `#0B3A82` | `#6FA2FF` | 品牌、主按钮、进行中课程 |
| `--neu-blue-deep` | `#07285C` | `#3D6FD4` | 悬停、按压 |
| `--warn` | `#C45A12` | `#F0A35A` | 低余额、即将上课 |
| `--danger` | `#B42318` | `#FF7A72` | 登录失败、已欠费 |
| `--ok` | `#1F7A4D` | `#5BD49A` | 充足、已刷新 |
| `--stroke` | `rgba(10,30,60,0.10)` | `rgba(255,255,255,0.10)` | 细线 |
| `--glow` | `0 8px 28px rgba(11,58,130,0.12)` | `0 12px 40px rgba(0,0,0,0.45)` | 展开阴影 |

**字体**

- Windows：`Segoe UI Variable` / `Microsoft YaHei UI` 回退
- macOS：`SF Pro` / `PingFang SC` 回退
- 数字（余额、倒计时）：同一家族的 tabular lining，避免数字跳动时宽度乱跳
- 不要用校名英文衬线体做 UI 字体

**圆角**

- 收起岛：胶囊，高度内垂直居中，圆角 = 高度/2
- 展开面板：顶边与岛一体，底边圆角 20px
- 余额卡片：14px
- 课表行：12px

**材质**

- 必须毛玻璃（Windows Acrylic / Mica；macOS vibrancy `hud` 或 `popover`）
- 1px 内高光描边，避免「一块灰矩形贴在天上」
- 展开时岛与面板是**同一块表面**，不要岛一套色、面板另一套

**Logo**

- 一个字：「泥」，或极简洞穴拱门 + 一点校蓝
- 收起态 Logo 不超过 18×18
- 不要完整校徽，避免官方感过重和版权问题

## 5. 平台与物理约束

设计必须按真实桌面像素想，不要按手机 390 宽出图。

| 项 | 规格 |
|---|---|
| 锚点 | 主屏上沿水平居中。多屏时跟鼠标所在屏 |
| 收起尺寸 | 宽 320–520（随内容变），高 **40**（Win）/ **38**（Mac，避开菜单栏时改为嵌进菜单栏右侧，见下） |
| 展开尺寸 | 宽 **420**（推荐）或 **480**，高自适应，上限 **560**，超出课表内部滚动 |
| 距顶 | **0**。贴屏幕上沿，展开时不要留一条空缝。Mac 若以后做「菜单栏模式」，收起态改为菜单栏图标 + 下拉 |
| 距摄像头 | 默认居中。挡镜头就**拖走**。不申请相机权限 |
| 永远置顶 | 是。全屏游戏时可自动隐藏（系统策略），设置开关 |
| 不抢焦点 | 悬停展开不要把正在打字的窗口抢走焦点 |
| 阴影 | 只在展开时出现，收起几乎无影，免得顶上一条脏带 |

**Windows 特殊**

- 任务栏自动隐藏时，岛仍贴屏幕顶，不跟任务栏
- 托盘要有图标。当前菜单：展开面板、刷新、复位岛、退出
- 支持 100% / 125% / 150% 缩放，出图请给 1x 和 2x

**macOS 特殊**

- 两种模式都要视觉稿：① 屏幕顶部悬浮岛（和 Win 一致）② 菜单栏图标下拉（更原生）
- 缺口屏 MacBook：用户自己拖开；不要为摄像头单独做设置项

**位置：只拖，不设**

设置里**不要**出现居中 / 偏左 / 偏右。挡镜头、躲小组件，按住岛拖开即可。

| 操作 | 行为 |
|---|---|
| 收起态按住拖 | 岛跟着鼠标走；仍始终置顶 |
| 展开态按住顶栏拖 | 同上，不要误触按钮 |
| 松手 | 写入本机；下次启动还原 |
| 双击收起态「泥」/ 托盘「复位岛」 | 回到顶部居中，y = 0 |
| Mac 菜单栏模式 | 设置里单独一项，换形态，不是坐标 |

约束：不要拖出当前屏工作区。

## 6. 信息架构

```
收起岛
  ├─ 品牌点（泥）
  ├─ 主信息：下一节课 或 当前课 或 「今天没课」
  └─ 辅信息：倒计时 / 最低余额警告（二选一，空间不够就只留课）

展开面板
  ├─ 顶栏：泥洞、教学周、刷新时间、设置
  ├─ 余额条：校园卡 | 网费 | 电费
  │    └─ 校园卡卡面底部：本月至今微型柱（示意，不是主阅读）
  ├─ 课表：今日，按时间；右侧「学期」进入学期课表
  └─ 底栏：上次同步 · 校园网/校外 · 课表来自本学期缓存

叠层（不是新桌面窗口风格）
  ├─ 登录（学号、密码、下一步）
  ├─ 二次验证（图形码 OCR 预填、短信码）
  ├─ 校园卡账单（点校园卡进入）
  ├─ 网费计费说明（点网费进入）
  │    ├─ 月份翻页：‹ 2026年9月 ›（默认本月，可看前几个月）
  │    ├─ 余额 / 该月花费 / 今日（看历史月则第三枚改「日均」）
  │    ├─ 该月 1…月末 日花费柱（DeepSeek 用量页那种，单色）
  │    └─ 选中日流水
  ├─ 学期课表（点「学期」进入）
  │    ├─ 教学周 ‹ 第 n 周 ›
  │    └─ 节次 × 星期 的密周历；格内只写课名；悬停看出课时间与地点
  ├─ 设置（先分类页，再进小类；退出登录在分类页底部）
  │    ├─ 外观
  │    ├─ 宿舍与余额
  │    ├─ 课表（第一周周一用年/月/日，不要系统 date 控件）
  │    ├─ 启动与登录
  │    ├─ 面板行为（自动隐藏 / 快捷键 / 悬停）
  │    └─ 上课提醒
  └─ 关于（点顶栏「泥洞」：简介、作者、版本）
```

钉住：登录/短信/账单/网费说明/学期打开时钉住；**设置不默认钉住**。快捷键按住钉住、松开取消。点岛或托盘「展开面板」钉住。细节见 [给AI.md](给AI.md)。

**不在 v1 做：** 充值下单、挂失、选课、成绩、图书馆、聊天、资讯 feed、广告、皮肤商店、多图表仪表盘、自定义任务/日程（v1.x 叠在同一张学期历上，先留位）。

## 7. 屏幕与状态（请全部出稿）

下列状态在 [`prototype/index.html`](prototype/index.html) 底部原型台可切换，浅色 / 深色都要成立。标注见本文 token 与 §8.1。

### 7.1 收起 · 默认

一条胶囊。贴顶时上沿直角（`flush`），离开顶边再恢复胶囊。左「泥」，中「高等数学 · 12:00」，右「23 分钟」。

无课日：中「今天没课」，右不显示倒计时，可显示「卡 399」。

### 7.2 收起 · 上课中

主信息改成进行中课程名，右侧变成「还剩 18 分钟」，用 `--neu-blue` 小点呼吸，不要整岛闪烁。

### 7.3 收起 · 警告

网费或电费低于阈值：右侧换成警告色小点 +「网费 0 元」。课名仍优先。若同时上课将开始，课优先，警告只留圆点。

### 7.4 收起 · 未登录 / 会话失效

中「登录泥洞」，右箭头。不要弹出系统通知轰炸。

### 7.5 展开 · 有课有余额（主状态）

从上到下：

1. 顶栏 44px：左标题「泥洞」，中「第 3 周 · 周一」，右齿轮与刷新
2. 三张余额卡横排，等宽，间距 8px
   - 校园卡 399.07 元；卡底一条**本月至今**微型花费柱（高 16px），提示可点开
   - 网费 0.00 元（警告色）；下一行「已用 1.90 GB」（本月 `sum_bytes`）。余额为 0 也要显示流量，不要被警告文案挤掉
   - 电费 剩余 xx 度 或「未绑定房间」
   - 校园卡可点进账单；网费可点进计费说明；电费 v1 不进二级页
3. 「今日」标题，右侧文字按钮「学期」
   - 每一行：时间段、课程名、教室
   - 已上完：降低对比
   - 正在上：蓝色左边条
   - 下一节：轻微强调
4. 底：灰色小字「12:03 同步 · 校园网」（课表缓存时间只写在学期看板和设置里）

### 7.6 展开 · 今日无课

课表区用短空状态：「今天洞里没课」。不要插画角色。

### 7.7 展开 · 新生未出课表

「教务还没有本学期课表。军训结束、选课落定后再刷新。」

### 7.8 展开 · 校外课表失败

余额仍可显示。课表区错误条：「校外连不上教务，连校园网后再试。」提供按钮「重试」。

### 7.9 登录

从岛向下展开的同一表面内，不要系统原生大窗。

- 学号
- 密码（可看清）
- 主按钮「进入泥洞」
- 辅助：「验证码登录（新设备可能要短信）」
- 文案：密码只存在这台电脑

### 7.10 二次验证

- 绑定手机掩码：`*******1479` 这种
- 图形验证码图 + 输入框 + 看不清换一张
- 输入框由**本机 OCR 预填**，用户可改；识别中用短骨架，失败则留空并把焦点放进框
- 小字：「本机识别，图不离开这台电脑。不对就改。」
- 不要自动点「发送」——OCR 只填图形码，发短信仍要用户点
- 发送短信按钮（倒计时 60s）
- 6 位短信码（手输，不做短信嗅探）
- 「信任这台电脑」开关，默认开
- 说明：图形码是学校的，不是泥洞的

### 7.11 设置

分组：

- 电费房间码（宿舍 3 位 + 寝室 4 位，浑南示例 `3510409` = 5 舍 A 区 0409）
- 低余额阈值（卡 20 元、网 5 元、电 10 度）
- 刷新间隔
- 开机自启
- 主题：跟随系统 / 浅 / 深
- Mac 菜单栏模式（仅 Mac）
- 课表：一行 `课表 · 9月1日已缓存`，右侧文字链「重新同步」（`--neu-blue`，12px，无底无边）。不要单独大按钮、不要 ghost 通栏
- 退出
- **不要**位置分组。拖动见 §5；拖丢用托盘复位

### 7.12 刷新中 / 部分失败

余额卡骨架屏（不要转圈占满岛）。某一张失败：卡片内「同步失败」，不影响其它卡。账单图未拉到时，校园卡仍显示余额，微型柱用骨架；点开账单页给空状态，不要假柱。

### 7.13 展开 · 校园卡账单（点校园卡）

同一表面内整板换成账单页（三张余额卡不再出现，改成三枚指标），不要新开系统窗。参考 **DeepSeek 开放平台「用量信息」**：上面三枚数字，下面一排按日的柱，无网格、无 Y 轴刻度。

父母按月给生活费，所以默认 **自然月**，不是滚动 30 日。可往前翻已经过完的月份。

从上到下：

1. 次顶栏 40px：左「‹ 校园卡」，右月份翻页 **‹  9月  ›**（当前月不让翻到未来；历史月显示 `2026年8月`）
2. 三枚指标，一行，不要卡片描边堆叠
   - 余额 399.07 元
   - 该月花费（只计消费、不计充值）
   - 看本月：今日 xx.xx；看历史月：日均 xx.xx
3. **该月日花费柱** 高 120px（见 §8.1）：1 号到月末，一天一列
4. 选中日标题：「9月7日 周一 · 3 笔 · 12.50 元」
5. 当日流水列表，内部滚动；充值行用 `--ok` 写 `+100.00`，消费行用主色写 `-12.50`
6. 空状态按日子：
   - 过去没刷卡：「这天没刷卡」
   - 本月里还没到的日子：柱位留空，tooltip「还没到」，不写「没刷卡」

**空 / 失败**

- 整月都没刷卡：「这个月卡没动过」+ 一条平基线，不要画假高峰
- 账单接口失败：保留余额数字，图表区「账单暂时拉不到」，按钮「重试」
- 该月翻页未完：底栏小字「本月可能不完整」，不要静默截断

浅色 + 深色都要出。看本月时默认选中 **今天**；看历史月时默认选中该月最后一天。

### 7.14 展开 · 学期课表（点「学期」）

同一表面整板换成周历，不要新开系统窗。数据来自**本学期缓存**，不是每天打教务。

1. 次顶栏：左「‹ 学期课表」，右 **‹ 第 3 周 ›**（可翻本学期各教学周）
2. 密周历：左列 6 个大节（1–2 … 11–12），下列**本周多数校区**的钟点；顶行 一…日。南湖/浑南上午不同，见表见开发文档 §7.5.1
3. 有课的格：**只写课名**（一行截断）。不要教室、不要老师
4. 悬停格子：tooltip `08:30–10:10 · 生命 B213`（这门课自己的时间 + 地点）。不要在表下再列当天课表
5. 底：小字「课表缓存于 9月1日 · 选课有变就重新同步」
6. 无缓存且校外失败：沿用 7.8
7. 自定义任务 / 日程：**v1 不画入口**。实现时格子预留第二色，v1.x 再叠用户事件

不要做成智慧东大那种全屏课表。420 宽只求「这周哪天下午有课」。

### 7.15 上课提醒 / 自动隐藏

上课提醒：到点把岛变成折叠大小，文案「即将上课 · 课名」，加粗课名 + 底部进度条，置顶 10 秒。不要外发光、不要尖角描边、不要系统 toast。

自动隐藏：折叠后再向上收进屏幕。不要留一条 8px 全透明缝（Windows 会点穿）。悬停热区在系统侧，比岛略宽略高即可。

### 8.1 日花费柱（DeepSeek 用量页密度）

这是 v1 **唯一**允许的图。学的是 platform.deepseek.com/usage 的日消费柱，不是财务 App 的蜡烛图。单色。默认一列 = 该月的一天。

```
  ‹ 校园卡                      ‹  9月  ›
  余额 399.07    本月 111.10    今日 12.50
  ┌────────────────────────────────────────┐
  │              ▇                       ▇ │  ← 今日，实色 --neu-blue
  │        ▇     ▇        ▇              ▇ │
  │   ▇    ▇  ▇  ▇     ▇  ▇              ▇ │
  │ ▇ ▇ ▇  ▇  ▇  ▇ ▇   ▇  ▇  ▇           · │  ← 8 号以后还没到，留空
  └────────────────────────────────────────┘
    1日              15日              30日
  9月7日 周一 · 3 笔 · 12.50 元
  · 11:32  一食堂        -12.00
  · 11:40  开水           -0.50
```

| 项 | 规格 |
|---|---|
| 图高 | 120px（含柱，不含 X 轴文字） |
| 柱 | 顶圆角 3px，底贴基线；按当月天数均分（28–31 列），间隙 3px |
| 颜色 | 单色。非今日：`--neu-blue` 38%（浅）/ 55%（深）；今日：100%；选中：100% + 柱顶 4px 圆点 |
| 零消费日 | **不画柱**，留空列，保持 1…月末对齐；不要 1px 灰桩排成栅栏 |
| 还没到的日子 | 同样留空；tooltip「还没到」；点了不装成「没刷卡」 |
| 充值 | **不加进柱高**。充值只出现在当日流水（绿色 +） |
| 网格 / Y 轴 | 不要。只有一条 `--stroke` 基线 |
| X 轴 | 只标 3 个点：1 日、月中、月末。本月第三点可写成「今天」若今天接近月末。字号 10px |
| 悬停 | 120ms 后 tooltip：`9月3日 周三 · ¥18.40 · 3 笔`。不改柱宽 |
| 点击 | 选中该日，下方列表换成那天的流水 |
| 翻月 | 柱高相对**该月最大日消费**重算，180ms ease。历史月从缓存画，不必转圈 |
| 微型柱（余额卡底） | 本月至今（1 号→今天）、高 16px、间隙 2px，整张卡是热区 |

不要折线、不要饼图、不要按食堂堆叠。科目只在流水行里用文字。不要「近 7 日 / 近 30 日」分段——生活费按月给。

## 10. 动效与交互

| 动作 | 行为 |
|---|---|
| 鼠标进入岛 | 延迟 120ms 展开，避免划过误开 |
| 鼠标离开面板 | 延迟 280ms 收起 |
| 点击岛 | 立即展开并钉住；Esc 收起但不取消钉住 |
| 刷新 | 图标旋转，数字 crossfade，不要整页闪白 |
| 上课前 15 / 5 分钟 | 收起态辅信息变警告色；不弹系统全屏 |
| 拖拽 | 按住岛（收起）或顶栏（展开）拖动；松手记本机坐标；拖出工作区要夹紧；设置可复位 |
| 点校园卡 | 进入账单叠层；点「‹」或 Esc 回到展开主态（若已钉住） |
| 账单翻月 | 左翻历史月；右翻到本月为止 |
| 悬停日柱 | tooltip；点击选日 |
| 点「学期」 | 进入学期周历；教学周左右翻 |
| 悬停周历格 | tooltip：大节时间 · 地点 |
| 图形码 | 打开验证层即本机 OCR；预填可改；失败留空 |

悬停是主交互。键盘：Esc 收起（不改钉住），Enter 在登录表单提交。默认唤出快捷键 Ctrl+Q。

## 11. 文案语气

短、东北话不要硬加。可以偶尔：

- 空课表：「今天洞里没课」
- 网费为 0：「网费见底了」

## 13. 禁止

- 不要仪表盘网格、雷达图、装饰性地图。**唯一例外：** 校园卡账单的日花费柱，且必须按 §8.1（无网格、无 Y 轴）
- 不要拟人吉祥物占展开高度
- 不要把智慧东大 App 界面搬过来
- 不要在余额旁放充值大按钮（v1 不支持充值，最多「去缴费大厅」文字链）
- 不要亮红全屏错误
- 不要为了品牌把背景做成泥色
