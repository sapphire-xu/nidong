# 泥洞 · 视觉设计说明

给视觉实现用。这不是营销海报，是一块长期停在桌面顶上的系统级小物件。请按「菜单栏 / 灵动岛」的密度来设计，不要做成手机 App 首页或数据大屏。

[`prototype/index.html`](prototype/index.html) 是旧的展开岛，只作早期对照。现行界面以本文和 [给AI.md](给AI.md) 为准。

产品：东北大学桌面小看板  
平台：Windows 11。macOS 安装包还没有  
形态：岛始终置顶、贴屏幕上沿；点岛打开系统窗口  
日期：2026-09-07 起稿。窗口模型 2026-09-26。任意门和主页三列课程行在其后。

---

## 1. 一句话

泥洞是贴在屏幕上方的一条窄岛。平时几乎不占地方，岛上只留一节课、倒计时和余额警告。点一下打开系统窗口，里面看卡里还有多少钱、网费还够不够、电会不会停、今天的课和日程。课上完后改看明天。日程页把课和自定义日程画在同一条时间轴上，日程用淡青绿色，和东大蓝放在同一张表上，不要另起一套皮肤。

## 2. 设计原则

1. **先是桌面公民，再是校园产品。** 收起态必须能和壁纸、刘海、摄像头、Windows 小组件和平共处。不要厚重描边、不要大 Logo。
2. **三秒读完。** 窗口里余额用大数字，今天的课用时间列表，一周用时钟轴，不要表格。
3. **东大蓝压住「泥洞」的土味。** 名字可以痞，界面必须干净。幽默只出现在空状态文案和关于页，不出现在余额数字旁边。
4. **状态比装饰重要。** 低余额、即将上课、登录失效、校外课表拉不到，都要有独立视觉，不能只靠 toast。
5. **深浅两套，跟系统。** 默认跟随 OS。宿舍关灯用深色；教室投影用浅色。
6. **不要拟物食堂、不要校徽当背景平铺、不要渐变彩虹卡片。**

## 3. 用户与场景

| 人 | 场景 | 界面要做什么 |
|---|---|---|
| 大一，宿舍电脑常开 | 打游戏/写作业时余光看一眼 | 收起态就能看到「下一节还有多久」 |
| 上课前 10 分钟 | 抓起鼠标确认教室 | 窗口里今日列表第一条是下一节 |
| 食堂排队 | 偶尔看卡余额 | 大数字，单位「元」 |
| 网费/电费见底 | 不想突然断 | 余额卡片变警告色，岛上同时有警告点。不要惊吓红满屏 |
| 第一次使用 | 学号密码 + 可能短信 | 窗口里先是登录。短信是下一步，不进左侧导航 |

## 4. 气质与品牌

**关键词：** 克制、贴边、夜色、东大蓝、洞口一盏灯。

「泥洞」不是泥巴 UI。把它理解成：校园生活的一条窄缝，缝里透出一点校蓝。

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg-island` | `#F4F7FB` 88% 毛玻璃 | `#12161C` 78% 毛玻璃 | 岛的底板 |
| `--bg-raised` | `#FFFFFF` | `#1C222C` | 余额卡片 |
| `--ink` | `#1A2433` | `#E8EEF6` | 主文字 |
| `--ink-dim` | `#5C6B80` | `#93A1B5` | 次要文字、单位 |
| `--neu-blue` | `#0B3A82` | `#6FA2FF` | 品牌、主按钮、进行中课程 |
| `--neu-blue-deep` | `#07285C` | `#3D6FD4` | 悬停、按压 |
| `--warn` | `#C45A12` | `#F0A35A` | 低余额、即将上课 |
| `--danger` | `#B42318` | `#FF7A72` | 登录失败、已欠费 |
| `--ok` | `#1F7A4D` | `#5BD49A` | 充足、已刷新 |
| `--agenda` | `#147A6E` | `#8FD4C6` | 日程小点。日程块和「文件分享服务已启用」药丸用更淡的青绿色，离线提示用 `--warn` |
| `--stroke` | `rgba(10,30,60,0.10)` | `rgba(255,255,255,0.10)` | 细线 |
| `--glow` | `0 8px 28px rgba(11,58,130,0.12)` | `0 12px 40px rgba(0,0,0,0.45)` | 岛的阴影 |

日程块和「文件分享服务已启用」药丸是同一套淡青绿。浅色底 `#D5F4EC`，字 `#0B3A82`。深色底 `#8FD4C6`，字 `#06231F`。药丸是胶囊，放在左侧导航底部靠右。分享没开时不显示。小点用 `--agenda`，比块底更深。

**字体**

- Windows：`Segoe UI Variable` / `Microsoft YaHei UI` 回退
- macOS：`SF Pro` / `PingFang SC` 回退
- 数字（余额、倒计时）：同一家族的 tabular lining，避免数字跳动时宽度乱跳
- 不要用校名英文衬线体做 UI 字体

**圆角**

- 岛：胶囊，高度内垂直居中，圆角 = 高度/2。贴顶时上沿直角
- 窗口里的卡片和课块跟随 Fluent 自己的圆角，不用岛的 20px 去改控件
- 课块、日程块：6px

**材质**

- 岛继续毛玻璃：现有 `styles.css` 的半透明底加模糊
- 窗口用 Fluent 主题的不透明底。2026-09-26 试过 `windowEffects: mica` 加透明窗口：系统标题栏按钮没有画出来，正文也看不到壁纸。按计划退回不透明底。岛和窗口是两块表面，不要做成从岛里长出来

**Logo**

- 一个字：「泥」，或极简洞穴拱门 + 一点校蓝
- 收起态 Logo 不超过 18×18
- 不要完整校徽，避免官方感过重和版权问题

## 5. 平台与物理约束

设计必须按真实桌面像素想，不要按手机 390 宽出图。

| 项 | 规格 |
|---|---|
| 锚点 | 主屏上沿水平居中。多屏时跟鼠标所在屏 |
| 岛 | 宽 **420**，高 **40**。贴顶时上沿直角 |
| 窗口 | 系统标题栏。初始 **1100×720**，最小 **880×560**。可缩放，进任务栏，不置顶。第一次打开在岛所在屏幕居中 |
| 距顶 | 岛的 **y = 0**。窗口不要贴着岛长出来 |
| 距摄像头 | 默认居中。挡镜头就**拖走岛**。不申请相机权限 |
| 永远置顶 | 只有岛。全屏游戏时只藏岛，窗口留着 |
| 不抢焦点 | 悬停把岛叫出来时不要抢走正在打字的窗口。点岛打开窗口时，窗口获得焦点 |
| 阴影 | 岛几乎无影，免得顶上一条脏带 |

**Windows 特殊**

- 任务栏自动隐藏时，岛仍贴屏幕顶，不跟任务栏
- 托盘要有图标。左键打开窗口。右键菜单先是校园卡、网费、电费余额（点击无动作），然后打开窗口、刷新、复位岛、退出
- 支持 100% / 125% / 150% 缩放，出图请给 1x 和 2x

**macOS 特殊**

- 两种模式都要视觉稿：① 屏幕顶部悬浮岛（和 Win 一致）② 菜单栏图标下拉（更原生）
- 缺口屏 MacBook：用户自己拖开；不要为摄像头单独做设置项

**位置：只拖，不设**

设置里**不要**出现居中 / 偏左 / 偏右。挡镜头、躲小组件，按住岛拖开即可。

| 操作 | 行为 |
|---|---|
| 按住岛拖 | 岛跟着鼠标走；仍始终置顶。位移达到 6px 才算拖，不打开窗口 |
| 松手 | 写入本机；下次启动还原 |
| 托盘「复位岛」 | 回到顶部居中，y = 0，高度仍是 40。不关窗口。连点岛只打开窗口，不要把岛拉回中央 |
| Mac 菜单栏模式 | 设置里单独一项，换形态，不是坐标 |

约束：不要拖出当前屏工作区。

## 6. 信息架构

```
岛
  ├─ 品牌点（泥）
  ├─ 主信息：下一节课 或 当前课 或 「今天没课」
  └─ 辅信息：倒计时 / 最低余额警告（二选一，空间不够就只留课）

窗口（系统标题栏，左侧七项导航；未登录且没有跳过时没有导航）
  ├─ 登录（学号、密码）
  ├─ 短信验证（登录的下一步，不进导航）
  ├─ 主页
  │    ├─ 校园卡 | 网费 | 电费
  │    ├─ 校园卡卡面底部：本月至今微型柱
  │    └─ 今日课和今日日程；加号添加日程。今日上完或今天没课，再列明日
  ├─ 日程：教学周时钟轴，07:30–22:30，周一到周日
  ├─ 账单
  │    ├─ 校园卡：月份、花费柱、当日流水
  │    └─ 网费：计费说明
  ├─ 工具箱：四个圆角方格。校园网自动登录、免流文件互传可点，其余写敬请期待。分享开着时，导航底部靠右有淡青绿药丸「文件分享服务已启用」
  ├─ 任意门：用系统浏览器打开固定网站
  ├─ 设置（六类仍在这一页里；退出登录在底部）
  └─ 关于：一句说明、作者、反馈邮箱；版本和检查更新在下方分隔线之后
```

没有钉住。点岛或托盘「打开窗口」只是把窗口叫到前面。细节见 [给AI.md](给AI.md)。

**不在 v1 做：** 充值下单、挂失、选课、成绩、图书馆、聊天、资讯 feed、广告、皮肤商店、多图表仪表盘。电费没有二级页。

## 7. 屏幕与状态（请全部出稿）

下面是现行窗口里要成立的状态，浅色 / 深色都要成立。标注见本文 token 与 §8.1。旧原型台里的「展开」不是现在的界面。

### 7.1 收起 · 默认

一条胶囊。贴顶时上沿直角（`flush`），离开顶边再恢复胶囊。左「泥」，中「高等数学 · 12:00」，右「23 分钟」。

今天没课、明天也没课：中「今天没课」，右不显示倒计时，可显示「卡 399」。今天没课但明天有课：中间是明天那门课的名字，右侧「明天 08:30」。今天的课已经上完、明天还有课：中间仍是「今天课上完了」，右侧换成明天的开始时间。

### 7.2 收起 · 上课中

主信息改成进行中课程名，右侧变成「还剩 18 分钟」，用 `--neu-blue` 小点呼吸，不要整岛闪烁。

### 7.3 收起 · 警告

网费或电费低于阈值：右侧换成警告色小点 +「网费 0 元」。课名仍优先。若同时上课将开始，课优先，警告只留圆点。

### 7.4 收起 · 未登录 / 会话失效

没跳过登录时：中「登录泥洞」，右箭头。点过「跳过登录」后不要写这句话，按今天没课或日程提醒显示，不要出示缓存里的课名和余额。不要弹出系统通知轰炸。

没网且上次没退出登录：不要进这一态。收起仍显示课/余额缓存；窗口里一条警告色浅底「离线状态 · 显示上次缓存」，不要「重新登录」按钮。

### 7.5 窗口 · 主页

系统标题栏和左侧导航已经占掉「泥洞 / 齿轮」。主页内容从上到下：

1. 页头：左「第 3 周 · 周一」，右刷新。不要再在页头放一枚齿轮
2. 三张余额卡横排，等宽
   - 校园卡 399.07 元；卡底一条**本月至今**微型花费柱（高 16px），提示可点开
   - 网费 0.00 元（警告色）；下一行「已用 1.90 GB」（本月 `sum_bytes`）。余额为 0 也要显示流量，不要被警告文案挤掉
   - 电费 剩余 xx 度，或「未绑定房间」。23:00–6:00 抓取失败但度数还在：度数后面写「 · 缓存」，不要改成「同步失败」，也不要拿掉度数。白天失败、度数还在：写「 · 同步失败」。没有度数才只显示「同步失败」
   - 校园卡可点进账单；网费可点进计费说明；电费没有二级页
3. 「今日」标题，右侧加号 + 文字按钮「日程 ›」
   - 每一行三列：时间段和状态、课程名、教师和地点。地点靠右，不要全部挤在左侧。最小窗口下不要改成左右两栏
   - 日程行：淡青绿小点，可点进去改
   - 已上完：降低对比
   - 正在上：蓝色左边条
   - 下一节：轻微强调
4. 底：灰色小字「12:03 同步 · 校园网」（课表缓存时间只写在日程页和设置里）。离线时写「离线状态」，不要弹出重新登录

### 7.6 窗口 · 今日无课 / 今日已上完

今天一门课都没有：写「今天没有课」。今日日程仍留在今天。明天有课或日程时，下面再加标题「明日」。

今日本来有课、已经全部下课：不列今日课程。一句「今日课程已上完」，还没结束的今日日程留在这句下面，然后是「明日」。

空状态不要插画角色。

### 7.7 窗口 · 新生未出课表

「教务还没有本学期课表。军训结束、选课落定后再刷新。」

### 7.8 窗口 · 校外课表失败

余额仍可显示。课表区：「校外连不上教务，连校园网后再试。」登录刚结束的超时不要写成这句话，见给AI「登录同步 vs 刷新」。

### 7.9 登录

登录在 `desk` 窗口里，不是从岛向下长出来的一块。

- 学号
- 密码（可看清）
- 主按钮「进入泥洞」
- 次按钮「跳过登录」。跳过后进入导航。校园卡、网费、电费、课程和账单写「登录后可用」或「需要登录」，工具箱、日程、任意门、设置、关于照常
- 辅助：「验证码登录（新设备可能要短信）」
- 文案：密码只存在这台电脑

### 7.10 二次验证

- 绑定手机掩码：`*******1479` 这种
- 图形验证码图 + 输入框 + 看不清换一张。图形码由用户自己填，程序不识别
- 发送短信按钮（倒计时 60s）
- 6 位短信码（手输，不做短信嗅探）
- 「信任这台电脑」开关，默认开
- 说明：图形码是学校的，不是泥洞的

### 7.11 设置

现行六类。已登录时底部是「退出登录」，先问是留下本机日程还是一起删掉。未登录时是「去登录」。没有刷新间隔，没有位置，没有 Mac 菜单栏开关。

- 外观：跟随系统 / 浅 / 深
- 宿舍与余额：电费房间码（宿舍 3 位 + 寝室 4 位，默认留空）、低余额阈值（卡 20 元、网 5 元、电 10 度）
- 课表：第一周周一用年/月/日三格。一行 `课表 · 9月1日已缓存`，右侧文字链「重新同步」（`--neu-blue`，12px，无底无边）。未登录时这行不可点，并写「登录后才能同步课表」。同步中：蓝字「同步中」+ 12px 小圈 + 行底一条细蓝线；成功：`--ok` 勾 +「已同步」，约 1.6s 回到文字链。不要单独大按钮
- 启动与登录：记住密码、自动登录、开机自启
- 面板行为：自动隐藏、快捷键、悬停唤出
- 上课提醒：开关、提前分钟、预览动效
- **不要**位置分组。拖动见 §5；拖丢用托盘复位

### 7.12 刷新中 / 部分失败

余额卡骨架屏（不要转圈占满岛）。某一张失败：卡片内「同步失败」，不影响其它卡。账单图未拉到时，校园卡仍显示余额，微型柱用骨架。账单页在数字回来前用加载态，不要画上一月的柱。

### 7.13 窗口 · 校园卡账单

账单是左侧导航里的一页，也是主页点校园卡进去的那一页。三张余额卡换成三枚指标。参考 **DeepSeek 开放平台「用量信息」**：上面三枚数字，下面一排按日的柱，无网格、无 Y 轴刻度。

父母按月给生活费，所以默认 **自然月**，不是滚动 30 日。可往前翻已经过完的月份。还没拿到该月时，总计和日均先写「-」，柱高按向右平移的正弦起伏。每根柱同一时刻是纯色，整排从选中的泥洞蓝过渡到未选中的浅蓝，颜色跟着正弦走。加载至少停 1.5 秒。列表文案每 0.5 秒在「加载中」「加载中.」「加载中..」「加载中...」之间换。

从上到下：

1. 页头：左标题「账单」，右分段「校园卡 / 网费」。悬停不要灰下划线，只保留当前选中的蓝条。两页切换用设置页那种左右平移（420ms，18px）。校园卡这段下面是月份行：上个月、`9月`（历史月写 `2026年8月`）、下个月。当前月不能翻到未来。不要做「‹ 返回校园卡」
2. 三枚指标，一行，不要卡片描边堆叠
   - 余额 399.07 元
   - 该月花费（只计消费、不计充值）
   - 看本月：今日 xx.xx；看历史月：日均 xx.xx
3. **该月日花费柱** 高 120px（见 §8.1）：1 号到月末，一天一列
4. 选中日标题：「9月7日 周一 · 3 笔 · 12.50 元」
5. 当日流水列表，内部滚动；充值行用 `--ok` 写 `+100.00`，消费行用主色写 `-12.50`
6. 空状态按日子：
   - 过去没刷卡：「这天没刷卡」
   - 本月里还没到的日子：柱位留空，tooltip「还没到」，不写「没刷卡」

**空 / 失败**

- 整月都没刷卡：「这个月卡没动过」+ 一条平基线，不要画假高峰
- 账单接口失败：保留余额数字，图表区「账单暂时拉不到」，按钮「重试」
- 该月翻页未完：底栏小字「本月可能不完整」，不要静默截断

浅色 + 深色都要出。看本月时默认选中 **今天**；看历史月时默认选中该月最后一天。

### 7.14 窗口 · 日程

教学周的时钟周视图。课表来自**本学期缓存**，日程来自本机。时间轴 07:30–22:30，每小时一条刻度，七列等宽，表头是该周日期。默认停在当前教学周，左右切换，范围沿用 `maxWeek`。

一块的顶边是（开始分钟 − 450）/ 900，高度是持续分钟 / 900，块高至少 22px。同一天里时间相交的块分成一簇，簇内按开始时间贪心分列，列宽等于这一簇的列数。课块用东大蓝，写课名、地点，有节次写「1-2 节」。日程块用淡青绿色，色值见文首调色板，和「文件分享服务已启用」药丸同一套。有地点就写在名称下面，原样显示。点课块看教师、地点、周次。点日程块打开编辑。页眉加号添加日程。未登录不画课程，仍可添加日程。没有教学周时按自然周翻页。

跨天日程按天切开，只画落在轴里的那段。完全落在轴外的不丢，列在当天列底的「轴外」。重复事项按每天或勾选的星期出现，点开仍是同一条。正在看的周如果包含今天，今天这一列画当前时间线。页底灰色小字：「日程存在这台电脑上。」再写课表缓存和去设置里同步。

### 7.16 添加日程

窗口里的对话框，不是新的系统窗。名称、地点、开始、结束（年/月/日 + 时:分，不要 `input type="date"`，也不用月历）、重复、提醒开关、提醒选项、备注。重复选每天或按星期；按星期勾星期；再选指定结束日期或指定重复次数。代码「提前一天指定时间」再要前一天的时刻。主按钮保存；编辑态可以删除。Esc 只关这个对话框。

### 7.15 上课提醒 / 自动隐藏

上课提醒：到点把岛变成折叠大小，文案「即将上课 · 课名」，加粗课名 + 底部进度条，置顶 10 秒。不要外发光、不要尖角描边、不要系统 toast。

自动隐藏：岛再向上收进屏幕。不要留一条 8px 全透明缝（Windows 会点穿）。悬停热区是岛的真实外接矩形，每边加 24 物理像素。悬停只把岛叫出来。

### 7.17 窗口 · 任意门

一页两段：「学校」「其他」。每行左侧一枚 20px 图标，然后是名称，右边短标签（仅校园网 / 随网络 / 校内渠道 / 直接打开 / 非官方资源共享站，或该项在做什么）。点一行打开系统浏览器。打开时右侧转圈并写「正在打开」，行底不要进度条。失败用一行警告，不要弹系统对话框。页首说明：学校站点校园网直连，人在校外改走 WebVPN，网关只能在校园网里用。不要在这一页嵌网页。其他里 NEU小站 的标签是「非官方资源共享站」，星标一行写「为本项目点个STAR吧qwq」。

### 7.18 窗口 · 工具箱

第一级四个方格，圆角和描边跟任意门行、设置行一样，8px，品牌色图标。校园网自动登录、免流文件互传这两格用品牌描边和 7% 品牌底，可点。其余两格写「敬请期待」，不可点。点进去后，用和设置页相同的滑入（420ms，从右 18px），进入下一级。页眉面包屑是「工具箱 › 校园网自动登录」或「工具箱 › 免流文件互传」，点「工具箱」用设置页的滑回（从左 18px）回到方格。下一级不要再套一层大外框。第一项名称是「登录规则设置」，用 Windows 风格的下拉，五种模式整句都要露出来，不要省略成一行点点。指定网络和校园网名称是普通输入框。指定网络右侧有「填入当前网络」，和输入框同一行，按钮不换行。说明用设置页那种 12px 灰色 hint。面板里有可点文字「这安全吗？」，样式跟关于页邮箱一样：品牌色、没有按钮框、悬停加下划线。点开是窗口内对话框，宽约 440px，标题「这安全吗？」，主按钮「知道了」。里面说明提交前核对学校证书，并提醒可疑的同名校园网要慎重。连接失败仍然只上岛，不要为失败再开这个对话框。分享开着时，左侧导航底部靠右显示胶囊「文件分享服务已启用」，淡青绿见文首。点它滑入免流文件互传。没开分享时不放这颗药丸。

### 7.19 设置返回

进入下一级，内容从右向左滑入 18px，420ms，`cubic-bezier(0.1, 0.9, 0.2, 1)`。回到总设置页，列表从左向右滑入同样的距离和时间，标题停着不动。系统开了减少动态效果时只改透明度。
