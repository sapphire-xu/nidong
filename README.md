# 泥洞

东北大学桌面看板。一条岛贴在屏幕上沿，展开看校园卡、网费、电费和今日课表。

「泥洞」是东大的戏称。非正式应用，不要冒充学校。作者 [sapphire_fic](https://github.com/sapphire-xu)。

> 东北大学桌面看板，致力于解决官方平台不便捷的问题。

## 功能介绍

- **贴顶岛**：平时一条 40px 高的圆角岛，点一下或悬停向下展开。可左右拖，不会拖出当前屏幕。
- **校园卡**：余额；点进去看本月花费柱和当日流水，可翻历史月。
- **校园网**：预存余额和本月已用流量；点开有计费说明。
- **宿舍电费**：填房间码后显示余量。每天 0:00–6:00 电费系统维护时沿用缓存，不把读不到的度数写成 0。
- **课表**：登录时拉整学期，之后今日课和周历都从本地推，不每天打教务。南湖 / 浑南作息按每门课自动选。点「学期」看周历。
- **上课提醒**：到点弹出折叠大小的置顶条（课名 + 倒计时），约 10 秒后收回。
- **校内 / 校外**：校园网直连一卡通和教务；校外先走学校 WebVPN 再拉数，登录和刷新是同一套逻辑。
- **本机凭据**：一号通学号密码进 Windows 凭据管理，cookie 和缓存在本机 `%APPDATA%\edu.neu.nidong`。没有自建服务器。
- **单实例**：已经在跑时再点快捷方式，会把现有的岛喊出来，不新开窗口。

不做充值、缴费下单、挂失、选课。学校改接口时抓数层可以换，界面不绑死某一版 URL。

## 安装（Windows）

需要 64 位 Windows。从 [Releases](https://github.com/sapphire-xu/nidong/releases) 下载 `nidong_1.0.0_x64-setup.exe`，按中文安装向导完成。装好后开始菜单里的名字是「泥洞」。

安装后开始菜单或桌面打开「泥洞」。通知区会有托盘图标。

macOS 安装包这一版还没有。

## 使用方法

### 第一次

1. 打开后岛上登录。学号、密码是**东北大学一号通**（和信息门户同一套）。
2. 新设备可能要图形验证码 + 短信二次认证。图形码可改，短信必须本人填。
3. 登录后会同步校园卡、网费、电费和课表。折叠岛上写「同步中…」时请等它走完。
4. 电费：齿轮 → **宿舍与余额** → 填电费房间码（和学校电费页同一个）。
5. 课表周次不对：齿轮 → **课表** → 填本学期第一周的周一，必要时点「重新同步」。

### 日常

| 操作 | 怎么做 |
|---|---|
| 展开 | 点折叠岛，或把鼠标放在岛上 |
| 收起 | 鼠标离开约 2 秒；或按 Esc |
| 钉住（不自动收） | 展开后点图钉。点折叠岛、打开账单 / 学期 / 关于时会自动钉住 |
| 刷新 | 展开后面板里的刷新，或托盘「刷新」 |
| 看账单 | 点校园卡那一格 |
| 看周历 | 点「学期」 |
| 网费说明 | 点网费那一格 |
| 关于 | 点顶栏「泥洞」 |
| 退出登录 | 齿轮 → 分类页最下 |

卡、网、电大约 20 分钟自动刷新。打开账单时会暂停拉账单，避免图被冲掉。课表不参与定时刷新。

### 托盘（通知区图标右键）

展开面板 → 刷新 → 复位岛（贴顶居中）→ 退出

### 可选设置

齿轮里分层：**外观**、**宿舍与余额**、**课表**、**启动与登录**、**面板行为**、**上课提醒**。

- **开机自启**、记住密码、自动登录：启动与登录
- **自动隐藏**：折叠后再过 3 秒收进屏幕上沿。上课提醒仍会弹出
- **快捷键唤出**：默认 `Tab+Q`，两键要在约 0.4 秒内一起按下
- **悬停展开**：鼠标停在原来岛的位置附近超过 1 秒
- **上课提醒**：上课前 N 分钟弹出（默认 15）

独占全屏游戏（D3D Exclusive）时岛会自动藏起，退出全屏再出现。无边框窗口化游戏可以被岛盖住。

同一时间只跑一个泥洞。

## 隐私

- 只跑在你自己的电脑上。
- 密码进系统凭据，不进普通 json，也不进 git。
- 抓数只打学校已经提供的页面和接口（一号通、校园卡、缴费大厅、门户、教务、WebVPN）。
- 退出登录不会清掉已记住的密码；要清请到系统凭据管理器里删。

## 从源码开发

需要 Node 18+、Rust stable、Windows C++ Build Tools。

```bash
git clone https://github.com/sapphire-xu/nidong.git
cd nidong
npm install
npm start
```

或双击仓库根目录的 `启动.bat`。首次仍用一号通学号密码登录。

打 Windows 安装包：

```bash
npm run build
npx tauri build
```

产物在 `src-tauri/target/release/bundle/nsis/泥洞_1.0.0_x64-setup.exe`。GitHub Release 里的文件名是 `nidong_1.0.0_x64-setup.exe`（同一份安装包）。

测上课提醒可以把「现在」拨到开课前：`scripts\set-now.bat`，测完 `scripts\clear-now.bat`。说明见 [docs/给AI.md](docs/给AI.md)。
