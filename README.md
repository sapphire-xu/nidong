# 泥洞

东北大学桌面看板。一条岛贴在屏幕上沿，点一下打开窗口，看校园卡、网费、电费、今日课表和本机日程。

作者 [sapphire_fic](https://github.com/sapphire-xu)。

> 东北大学桌面看板，致力于解决官方平台不便捷的问题。

不适用于东北大学秦皇岛分校。

## 功能介绍

- **贴顶岛**：只显示下一节课、倒计时和余额警告。点一下打开窗口。悬停不会把岛变高。默认开自动隐藏，可按 Ctrl+Q 把岛叫出来。
- **窗口**：系统标题栏。里面是主页、日程、账单、任意门、设置、关于。关掉只是藏起来，再点岛回到刚才的页面。
- **校园卡**：主页看余额；账单页看本月花费柱和当日流水，可翻历史月。
- **校园网**：预存余额和本月已用流量；账单页的另一段是计费说明。
- **宿舍电费**：填房间码后显示余量，留在主页。每天约 23:00–6:00 电费系统经常连不上，这段时间同步失败就显示上次缓存。
- **课表**：登录时拉整学期，之后每天自动再同步一次，老师调课不用手点。也可以手动刷新。日程页是教学周的时钟周视图，课和自定义日程画在同一条时间轴上。今日课上完，或今天本来没课、明天有课，主页都显示明日课程。
- **日程**：主页或日程页的加号添加。必须有起止时间，可设提醒、名称和备注。和课重叠时并排。跨天的按天切开。落在早上 7:30 前或晚上 22:30 后的，列在当天列底。
- **离线**：没网时若上次没退出登录，窗口直接进主页，并提示「离线状态」，不会要求重新登录。
- **上课提醒**：上课前 15 分钟（时间可修改）在岛上弹出一条置顶提醒，约 10 秒后收回。点这下岛会打开窗口。开了提醒的日程同样到点弹出。
- **任意门**：窗口里打开浏览器进固定网站。学校站点在校园网直连，人在校外时改走 WebVPN；校园网网关只能在校园网里开。浏览器不带泥洞自己的登录状态，校外仍要在网页里登一次 WebVPN。
- **校内 / 校外**：校园网直连一卡通和教务；校外先走学校 WebVPN 再拉数据。
- **本机凭据**：一号通学号密码进 Windows 凭据管理，cookie 和缓存在本机 `%APPDATA%\edu.neu.nidong`。
- **单实例**：已经在跑时再点快捷方式，会叫出岛并打开窗口，不另起一份程序。

不做充值、缴费下单、挂失、选课。学校改接口时抓数层可以换，界面不绑死某一版 URL。

## 安装（Windows）

需要 64 位 Windows。从 [Releases](https://github.com/sapphire-xu/nidong/releases) 下载 `nidong_2.0.0_x64-setup.exe`，按中文安装向导完成。装好后开始菜单里的名字是「泥洞」。

安装后开始菜单或桌面打开「泥洞」。通知区会有托盘图标。

macOS 安装包这一版还没有。

## 使用方法

### 第一次

1. 打开后岛上登录。学号、密码是**东北大学一号通**（和信息门户同一套）。
2. 新设备可能要图形验证码 + 短信二次认证。图形码可改，短信必须本人填。
3. 登录后会同步校园卡、网费、电费和课表。折叠岛上写「同步中…」时请等它走完。
4. 电费：打开窗口 → **设置** → **宿舍与余额** → 填电费房间码（和学校电费页同一个）。留空表示还没绑定。
5. 课表周次不对：**设置** → **课表** → 填本学期第一周的周一，必要时点「重新同步」。

### 日常

| 操作 | 怎么做 |
|---|---|
| 打开窗口 | 点岛，或托盘「打开窗口」。再点一次只是把窗口提到前面 |
| 关掉窗口 | 点窗口的关闭。岛还在，下次打开停在刚才的页面 |
| 自动隐藏 | 岛露出来约 3 秒、鼠标不在岛上时收进屏幕上沿。Ctrl+Q 或在原位置悬停约 1 秒，只把岛叫出来 |
| 刷新 | 主页里的刷新，或托盘「刷新」 |
| 看账单 | 主页点校园卡，或左侧「账单」 |
| 看一周课和日程 | 左侧「日程」，或主页的「日程」 |
| 添加日程 | 主页「添加日程」，或日程页的加号 |
| 网费说明 | 主页点网费，账单页切到「网费」 |
| 打开学校网站 | 左侧「任意门」。网关只能在校园网里开 |
| 关于 | 左侧「关于」 |
| 退出登录 | 设置页底部 |

卡、网、电大约 20 分钟自动刷新。打开账单时会暂停拉账单，避免图被冲掉。课表每天自动同步一次，同一天后面的余额刷新不再打教务。没网时刷新仍显示上次缓存。

### 托盘（通知区图标右键）

点击托盘小图标 → 打开窗口 / 刷新 / 复位岛（贴顶居中）/ 退出

### 可选设置

设置里仍是六类：**外观**、**宿舍与余额**、**课表**、**启动与登录**、**面板行为**、**上课提醒**。退出登录在设置页底部。

- **启动与登录**：可开关：记住密码、自动登录、开机自启
- **自动隐藏**：岛露出来后再过 3 秒收进屏幕上沿。上课提醒仍会弹出。悬停唤出只叫岛，不打开窗口。

独占全屏游戏（D3D Exclusive）时岛会自动藏起，退出全屏再出现。无边框窗口化游戏可以被岛盖住。

同一时间只跑一个泥洞。

## 隐私

- 只跑在你自己的电脑上。
- 密码进系统凭据，不进普通 json，也不进 git。
- 抓数只打学校已经提供的页面和接口（一号通、校园卡、缴费大厅、门户、教务、WebVPN）。
- 退出登录不会清掉已记住的密码。关闭记住密码时删除。

## 从源码开发

需要 Node 18+、Rust stable、Windows C++ Build Tools。

```bash
git clone https://github.com/sapphire-xu/nidong.git
cd nidong
npm install
npm start
```

或双击仓库根目录的 `启动.bat`。首次仍用一号通学号密码登录。

打 Windows 安装包：

```bash
npm run build
npx tauri build
```

产物在 `src-tauri/target/release/bundle/nsis/泥洞_2.0.0_x64-setup.exe`。GitHub Release 里的文件名是 `nidong_2.0.0_x64-setup.exe`（同一份安装包）。

测上课提醒可以把「现在」拨到开课前：`scripts\set-now.bat`，测完 `scripts\clear-now.bat`。说明见 [docs/给AI.md](docs/给AI.md)。
